赤刃亭isポートフォリオ — はじめに

■ プレビュー
index.html をブラウザで開くと確認できます。

■ GitHub Pagesで公開
1. GitHubでリポジトリを作成します。
2. このZIPを解凍し、中身（index.html と assets フォルダ）をリポジトリの直下にアップロードします。
3. Settings → Pages → Deploy from a branch を選びます。
4. Branch: main / Folder: /(root) を選んで保存します。

■ 画像の差し替え
画像ファイル名を変えずに上書きしてください。
トップ背景: assets/top-background.jpg
ABOUT背景: assets/about-bg.jpg
作品画像: assets/works/ 内の各ファイル

作品画像は差し替え用の仮画像です。ご自身の作品画像で上書きしてください。
画像形式をPNG/WebPに変更する場合は、index.html内の該当する画像パスの拡張子も変更します。
